Try it yourself

  1. Open a cloud session on the repo and run ./whereami.sh.
  2. Edit the environment in Claude Code settings. For example, allow example.com or add a setup script like apt-get install -y cowsay.
  3. Start a new session and run the script again. The repo hasn't changed, so any difference comes from the environment.
